# DOCUMENTAÇÃO COMO CÓDIGO:

## uma abordagem para a gestão do conhecimento no setor público

**Aluna**: Maria Eduarda Ferreira Oliveira Duque

**Orientadora**: Renata de Souza França

*2026*

<!--s-->

## Tema e delimitação

Gestão do conhecimento e preservação da memória institucional

na Administração Pública por meio da abordagem *Docs as Code*

<!--s-->

## Objetivos

- **Geral**: investigar a aplicabilidade dos princípios do Docs as Code como estratégia de mitigação da perda de memória institucional na Administração Pública

- **Específicos**:

  1. identificar os fatores que causam a fragmentação da documentação no setor público

  2. correlacionar as práticas de Docs as Code com as etapas da gestão do conhecimento

  3. analisar os requisitos técnicos, normativos e as barreiras culturais para sua implementação

  4. propor diretrizes de fluxo de trabalho baseado em Docs as Code

<!--s-->

## Justificativa

- Rotatividade e aposentadoria de servidores levam à perda de conhecimento

- Nenhum trabalho relaciona *Docs as Code* à Administração Pública

- Pesquisa do Ipea (2014) com 81 organizações federais:

  - práticas de **processo**: apenas **10%** implantadas e com resultados

  - práticas de **tecnologia**: **22%** implantadas e com resultados
